# SEO & GEO

## Schema
Organization, AutoDealer per anläggning, AutoRepair department, AutoPartsStore vid behov, BreadcrumbList samt Product/Offer endast när pris och lagerstatus hålls aktuella.

## AI/GEO
Viktiga sidor ska ha tidigt svar, verifierade fakta, vem lösningen passar, lokal expert, relaterade lagerbilar, FAQ och senast uppdaterad när freshness spelar roll.

## Internlänkning
Hub → modell → lager → offert.
Modell → jämförelse → sibling.
Modell → påbyggnad → branschlösning.
Anläggning → säljare/verkstad → lager.
Guide → relevant modell → offert.
